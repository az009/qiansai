# CM4 RTOS 完整移植 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把队友 `partner/Protocol_Analysis-main` 的 CM4 RTOS 完整架构(Proto_Select + Callback_Task)移植过来替代裸机循环,CM7 保持现有显示,融合成"外部信号→CM4→shm→CM7 显示"的完整链路。

**Architecture:** CM4 FreeRTOS(`Proto_Select` task 调度,每协议一个 `Callback_Task` 收数据 push shm),CM7 TouchGFX(waveWidget 读 shm head-6 显示)。配置 IPC 走 `HSEM_ID_CONFIG=1`(两边一致)。shm 裸字节接口(Callback_Task push 裸数据,不带队友的 magic/统计头)。

**Tech Stack:** STM32H747 双核,FreeRTOS(CM4),TouchGFX(CM7),HAL timebase 走 TIM(关键:解 SysTick 卡死),共享内存 SRAM1。

**Spec:** [docs/superpowers/specs/2026-07-08-m4-rtos-port-design.md](../specs/2026-07-08-m4-rtos-port-design.md)

**回滚点:** `9aeac82`(Settings 自动刷新)。任何步骤卡死 → `git reset --hard 9aeac82`(会丢 MUX/ADC,用户已接受)。
